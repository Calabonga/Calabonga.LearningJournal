# Дневник обучения (Calabonga.LearningJournal)

Консольное приложение для учёта времени, потраченного на учёбу: записи по темам, отчёты и дневная цель. Проект создан как сквозной учебный пример курса «Изучаем C# вместе с ИИ: с нуля до первого проекта» на Stepik.

Курс: [ссылка на курс — будет добавлена]

## Возможности

* добавление записей: дата, тема, минуты, заметка;
* проверка ввода и понятные сообщения об ошибках;
* хранение в файле JSON с безопасной записью через временный файл и сохранением повреждённого файла;
* отчёт: сумма часов, дни с выполненной целью, лучшие темы;
* модульные тесты на логику подсчётов и хранилище.

## Технологии

C# 15, .NET 11, System.Text.Json, LINQ, xUnit.

## Как запустить

```powershell
git clone https://github.com/Calabonga/Calabonga.LearningJournal.git
cd Calabonga.LearningJournal
dotnet run --project Calabonga.LearningJournal
```

Тесты:

```powershell
dotnet test
```
